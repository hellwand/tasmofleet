---
section: Fixed
---

Devices list: a column is as wide as you set it, in pixels, at every window width. A double-click fit makes that one column as wide as its content and changes no other column; the last data column has a resize handle and can be made narrower; a window wider than the table keeps the room left over empty before Power and the row menu instead of stretching every column; and the row menu column is always as wide as its button (it has no resize handle and no saved width). A layout saved by an earlier version comes back with no column narrower than its content wherever the window holds them, without a reset (#828)
